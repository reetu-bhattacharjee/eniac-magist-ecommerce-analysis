# Eniac–Magist E-commerce Analysis

## Overview

This repository contains a sample data-science study evaluating whether Magist could support Eniac's potential expansion into the Brazilian market.

The project uses a Magist e-commerce dataset to analyze tech-product sales, pricing, seller performance, and delivery reliability. It combines SQL analysis with Python checks and is intended for learning and portfolio purposes.

> **Important:** This is a sample study.  Magist is modeled as a real-sized Brazilian Software-as-a-Service (SaaS) company. Same for Eniac. The dataset is historical and the conclusions are illustrative only.

## Questions explored

- Which product categories can be considered tech categories?
- How many tech and non-tech products were sold?
- What share of sales came from tech products?
- What are the average prices of tech and non-tech products?
- Are expensive tech and non-tech products popular?
- How many tech sellers are active?
- What revenue is generated by tech products?
- How long do deliveries take?
- How many orders are delivered on time or late?
- Are heavier products more likely to be delayed?

## Running the Python analysis

From the repository root, run:

```bash
python analyze_magist.py
```

The script prints key summary statistics as JSON, including sales, revenue, seller, pricing, and delivery metrics.

## Tableau Public

The CSV tables can be imported into Tableau Public. Use relationships between the tables rather than joining every table into one flat table:

```text
customers → orders → order_items
products → order_items
sellers → order_items
product_categories → products
```

Recommended relationship fields include:

- `customer_id`
- `order_id`
- `product_id`
- `seller_id`
- `product_category_name`

Use `COUNTD(order_id)` for distinct orders and `COUNT(order_item_id)` for sold item units. This helps avoid double-counting when working with tables at different levels of detail.

## Sample conclusion
Based on this sample analysis, Magist does not appear to be a strong partner for Eniac. Although Magist shows meaningful tech-product activity and generally good delivery performance, its third-quartile tech-product price is substantially below Eniac's average product price. This indicates a significant mismatch between Magist's marketplace product profile and Eniac's premium, Apple-focused positioning. The data also does not confirm Apple-specific product availability, current performance, profitability, or contractual suitability.

## Limitations

- The study is educational and uses a historical sample dataset.
- The data does not represent current operational performance.
- Product prices are analyzed as recorded in the dataset; currency and profitability should be validated before making business decisions.
- Revenue calculations based on product price do not necessarily include freight, discounts, fees, refunds, or profit.
- The dataset does not provide enough information to confirm Apple-specific assortment or Brazilian market fit.
